# Pill

Die hellblaue Pill in Versalien: die eine Hauptaktion pro Band, Grafik oder Szene.

- `bw-pill button` (52 px hoch) in Leiste und Karten; `bw-pill bw-pill--xl button-xl` (68 px, mindestens `cta-min`) für die Hauptaktion eines Bands, mit Pfeil rechts. Schein `shadow-cta`.
- **Eine Pill pro Band.** Ein Zweitweg ist ein `bw-textlink` (halbfett, hellblau unterstrichen), nie ein zweiter Knopf daneben.
- Unter der Hauptaktion eine `bw-facts`-Zeile mit den Fakten (Kostenlos, 7 Etappen, 8 Werkzeuge).
- Weiss auf `cta` hält 3.1:1: dokumentierte Ausnahme, deshalb nur grosse, fette Versalien. `bw-pill--ink` ist der dunkle Knopf auf einem hellblauen Band.
- Beschriftungen aus dem Bestand: «Ich will Zeit sparen», «Zeit sparen», «Analyse buchen», «PDF Logbuch zuschicken». Hover: das Label rutscht nach oben weg, eine Kopie von unten nach (240 ms).
