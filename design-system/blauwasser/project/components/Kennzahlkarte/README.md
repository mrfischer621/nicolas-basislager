# Kennzahlkarte

Social-Kachel 1080 x 1350 (4:5) für eine belegte Zahl: Wortmarke oben, Dachzeile, riesige Zahl, Aussage mit Marker, Quelle unten.

- Fläche `background` mit Polarnetz, Rand 96 px. Zahl in Albert Sans 900, Aussage `ov-headline`, Quelle `ov-role` in `foreground-muted`.
- **Nur Zahlen mit Quelle** aus dem Logbuch oder `content/`. Keine Kundenzahlen, keine Prozentversprechen.
- Varianten: Zitat einer der drei Stimmen (`Zitat`) statt Zahl; Tiefsee-Fläche mit Pointe in `cta` statt Marker.
