# Glossar

Begriffe im CRM, verbindlich für Oberfläche, Hilfetexte und Dokumentation. Schweizer Rechtschreibung (ss, kein ß), Du-Form in der App. Texte, die an Kundinnen und Kunden gehen (Rechnungen, Offerten, Vorlagen), bleiben in der Sie-Form.

| Begriff | Bedeutung | Nicht verwenden |
|---|---|---|
| **Unternehmen** | dein eigenes Geschäft (Blauwasser IT, Freiluftchuchi). Einstellungen gelten pro Unternehmen; Zahlen werden nie über Unternehmen hinweg zusammengezählt. | Firma (für das eigene) |
| **Firma** | Kunde oder Interessent als Organisation | Kunde, Organisation, Account |
| **Person** | Ansprechperson einer Firma; eine davon ist die **Hauptperson** | Kontakt, Kontaktperson |
| **Kontakte** | Navigationspunkt für Firmen und Personen | Stammdaten, Kunden |
| **Lead** | noch nicht qualifizierter Interessent (Recherche, Website-Anfrage) mit Status Neu, Kontaktiert, Kein Interesse | Recherche-Deal |
| **Deal** | Verkaufschance ab Erstgespräch, in einer **Phase** der **Pipeline** | Opportunity, Chance |
| **Phase** | Schritt in der Pipeline (Erstgespräch, Analyse, Offerte, Verhandlung, Gewonnen) mit Wahrscheinlichkeit | Stufe, Spalte (in der Oberfläche) |
| **Offerte** | Angebot an eine Firma; Nummer OF-JJJJ-NNN (ältere: AN-) | Angebot |
| **Umgewandelt** | Offerte, aus der eine Rechnung entstanden ist (gespeichert als `bestaetigt`) | Bestätigt |
| **Abgelaufen** | versendete Offerte nach Ablauf der Gültigkeit (abgeleitet) | Überfällig (bei Offerten) |
| **Rechnung** | Nummer RE-JJJJ-NNN, mit QR-Teil | Faktura |
| **Überfällig** | versendete Rechnung nach der Fälligkeit (abgeleitet, nicht gespeichert) | |
| **Zahlungsdatum** | Tag des Zahlungseingangs; entscheidet, in welchem Jahr eine Einnahme zählt | |
| **Buchung** | Einnahme oder Ausgabe im Milchbüechli, mit Beleg | Transaktion |
| **Lieferant / Zahler** | Gegenpartei einer Buchung | |
| **Wiederkehrend** | Buchung, die regelmässig anfällt (Abo, Miete); Grundlage der Fixkosten | |
| **Wiederkehrender Umsatz** | Rechnung für Wartung oder Retainer; Grundlage des MRR | |
| **Leistung** | Produkt oder Dienstleistung als Vorlage für Positionen | Produkt (in der Navigation) |
| **Zeit** | erfasste Arbeitszeit auf einem Projekt | Zeiteintrag (in Überschriften) |
| **verrechenbar** | eine Zeit darf in Rechnung gestellt werden | |
| **verrechnet** | eine Zeit steht auf einer Rechnung oder ist von Hand als verrechnet markiert | |
| **nicht verrechnet** | verrechenbar und noch auf keiner Rechnung | offen (bei Zeiten in Überschriften) |
| **Standardsatz** | Stundensatz, wenn weder Projekt noch Firma einen haben (Einstellungen) | |
| **Cockpit** | Startseite: Zu erledigen, Steuerung, Kennzahlen | Dashboard |
| **Berichte** | Übersicht, Erfolgsrechnung, Jahresabschluss, Export | Auswertungen |
| **Frist** | Termin wie Steuererklärung oder AHV-Akonto, optional wiederkehrend | |
| **Kontostand** | erfasster Stand des Geschäftskontos, Ausgangspunkt der Liquiditätsvorschau | |
